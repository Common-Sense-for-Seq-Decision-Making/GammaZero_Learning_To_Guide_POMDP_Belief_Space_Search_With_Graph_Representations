Four Domains, One Graph Architecture

The same 4-node-type graph structure (Object, Attribute, Action, Global) handles all domains. Only the domain-specific construction rules change.

LD
LightDark
1D localization: navigate to goal under position uncertainty. Observations improve near the "light" region. Must gather information before committing.
→
Train: LD(5)
Test: LD(10)
2x generalization
RS
RockSample(n,k)
Information gathering on n×n grid with k rocks of unknown quality. Distance-dependent noisy sensor. Check rocks, then sample good ones and exit.
→
Train: RS(5,5)-(10,10)
Test: RS(25,25)
6.25x area
MOS
MultiObjectSearch(n,k)
Find and declare k hidden objects on n×n grid using range-limited sensor. Robot must navigate, scan for objects, then declare locations with confidence.
→
Train: MOS(3,2)-(4,3)
Test: MOS(8,6)
4x area, 2x objects
RG
Rearrangement(n,k)
Mobile manipulation: locate k objects with unknown positions, then transport them to goal locations on n×n grid. Combines perceptual uncertainty with multi-step planning.
→
Train: RG(3,2)-(4,3)
Test: RG(8,5)
4x area, 2.5x objects
Key Pattern: Each domain maps to the same 4-node-type structure: Actions (blue) connect to Objects (circles), which connect to Attributes (orange, opacity = belief) via Global (diamond). Adding more objects just adds more nodes — the same GNN weights process all sizes.
